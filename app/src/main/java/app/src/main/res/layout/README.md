# CodeAlpha_RandomQuoteGenerator

An Android Random Quote Generator application developed as part of the CodeAlpha Android Development Internship.

## Features
- **Dynamic Quote Generation:** Displays randomized inspirational and programming quotes on button click.
- **Native Android Share Sheet:** Allows users to share their favorite quotes directly to other apps (WhatsApp, Messages, etc.).
- **Clean Card UI:** Built with Material CardView and clean typography.

## Tech Stack
- **Language:** Java
- **UI:** Android XML / Material Components / CardView
- **IDE:** Android Studio
